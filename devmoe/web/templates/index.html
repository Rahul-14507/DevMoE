Seamless Developer Setup

OpenAI Drop-In Replacement

DevMoE exposes an OpenAI-compatible API at http://localhost:8080/v1. You can configure it as the custom base URL in Cursor, VS Code Continue, Cline, Claude Dev, Aider, or scripts.

1. Cursor / Windsurf / VS Code Continue Configuration

{
  "models": [
    {
      "title": "DevMoE (Auto Hybrid Router)",
      "provider": "openai",
      "model": "devmoe-auto",
      "apiBase": "http://localhost:8080/v1",
      "apiKey": "dummy"
    },
    {
      "title": "DevMoE (Local High-Param Only)",
      "provider": "openai",
      "model": "devmoe-local",
      "apiBase": "http://localhost:8080/v1",
      "apiKey": "dummy"
    }
  ]
}

2. Python OpenAI Client

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="dummy"
)

response = client.chat.completions.create(
    model="devmoe-auto",
    messages=[
        {"role": "user", "content": "Design a raft consensus system with mutex locks"}
    ]
)

print(response.choices[0].message.content)
print("Metadata:", response._devmoe_meta)

3. Direct cURL Request

curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "devmoe-auto",
    "messages": [{"role": "user", "content": "Write a regex to extract email addresses"}]
  }'
